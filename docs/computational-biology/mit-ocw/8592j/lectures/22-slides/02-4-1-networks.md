# 4.1 Networks

The primary elements of a network are its nodes. These can be a set of genes or proteins in the cell, the interconnected neurons of the brain, or organisms in an ecosystems. Links between nodes indicate a direct interaction, for example between proteins that bind, neurons connected by synapses, or organisms in a predator/prey relationship. In its most basic form, the network can be represented by nodes i = 1, 2, · · · , N as points of a graph, and links Lij as edges between pairs of points. Excluding self-connections, the maximal number of

70

possible links is N(N − 1) with directed connections (e.g. as in a predator/prey relation), and N(N − 1)/2 for undirected links (as in binding proteins). A subgraph is a portion of the total network, say with n nodes and l links. Some types of subgraphs have specific names; e.g. a cycle is a path starting and ending at the same node, while a tree is a branching structure without cycles.
