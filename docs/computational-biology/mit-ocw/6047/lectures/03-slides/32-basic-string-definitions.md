- A _string_ S – Ordered list of characters

   - Written contiguously from left to write

- A _substring_ S[i..j]

   - all contiguous characters from i to j

   - Example:  S[3..7] = abaxa

- A _prefix_ is a substring starting at 1

- A _suffix_ is a substring ending at |S|

- |S| denotes the number of characters in string S
