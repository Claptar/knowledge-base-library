#### Accessing the help files

##### **`?mean`**

Get help of a particular function. **`help.search(‘weighted mean’)`** Search the help files for a word or phrase. **`help(package = ‘dplyr’)`** Find help for a package.

#### More about an object

**`str(iris)`** Get a summary of an object’s structure. **`class(iris)`** Find the class an object belongs to.
