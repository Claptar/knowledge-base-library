- Conditional independence, given _C_ , is defined as independence under probability law P( _· | C_ )

   - Assume _A_ and _B_ are independent

- Recall that P( _A ∩ B_ ) = P( _A_ ) _·_ P( _B | A_ )

- Defn: P( _A ∩ B_ ) = P( _A_ ) _·_ P( _B_ )

- Symmetric with respect to _A_ and _B_

- applies even if P( _A_ ) = 0

- implies P( _A | B_ ) = P( _A_ )
