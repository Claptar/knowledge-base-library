Given a sample space Ω:

1. **Nonnegativity: P** ( _A_ ) _≥_ 0 for each event _A_

2. **Additivity:** If _A_ and _B_ are disjoint events, then

**P** ( _A ∪ B_ ) = _P_ ( _A_ ) + _P_ ( _B_ )

If _A_ 1 _, A_ 2 _, . . . ,_ is a sequence of disjoint events,

**P** ( _A_ 1 _∪ A_ 2 _∪· · ·_ ) = _P_ ( _A_ 1) + _P_ ( _A_ 2) + _· · ·_

3. **Normalization P** (Ω) = 1
