# 4.4.3. The Ornstein-Uhlenbeck process

If ( _B_ ( _t_ ) _, t ≥_ 0) is a standard Brownian motion it is easily shown by Brownian scaling that the process ( _e_<sup>_−r_</sup> _B_ ( _e_<sup>2</sup><sup>_r_</sup> ) _, r ∈_ R) is a two-sided stationary Gaussian Markov process, known as an _Ornstein-Uhlenbeck process_ . See [370, Ex. III (1.13)] for further discussion.
