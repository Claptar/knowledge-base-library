Except where otherwise specified, a Brownian motion _B_ is assumed to be onedimensional, and to start at _B_ 0 = 0, as in the above definition. If _βt_ = _x_ + _Bt_ for some _x ∈_ R then _β_ is a _Brownian motion started at x_ . Given a Brownian motion ( _Bt, t ≥_ 0) starting from 0, the process _Xt_ := _x_ + _δt_ + _σBt_ is called a _Brownian motion started at x with drift parameter δ and variance parameter σ_<sup>2</sup> _._ The notation P<sup>_x_</sup> for probability or E<sup>_x_</sup> for expectation may be used to indicate that _B_ is a Brownian motion started at _x_ rather than 0, with _δ_ = 0 and _σ_<sup>2</sup> = 1.
