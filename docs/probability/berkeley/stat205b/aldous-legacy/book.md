# Reversible Markov Chains and Random Walks on Graphs {#reversible-markov-chains-and-random-walks-on-graphs}

(by Aldous and Fill: unfinished monograph)

In response to many requests, the material posted as separate chapters since the 1990s (see bottom of page) has been recompiled as a single PDF document which nowadays is searchable. Here it is

[Reversible Markov Chains and Random Walks on Graphs](book.md) (PDF, 516 pages).

Also, Peter Ralph has kindly run it through LaTeXML, to make a nice HTML version, and here it is

[Reversible Markov Chains and Random Walks on Graphs](https://www.stat.berkeley.edu/~aldous/205B/Book_Ralph/book.html) (HTML).

Some things to note

- The content has not been changed.
- The chapters which previously had integer numbers have retained the same numbers; other chapters have now acquired integer numbers, as indicated below.
- Cross-refs between chapters are neither explicit nor reliable.
- There is some minor duplication of sections.

Suggested BibTeX citation:


    @misc{aldous-fill-2014,
        AUTHOR = {Aldous, David and Fill, James Allen},
         TITLE = {Reversible Markov Chains and Random Walks on Graphs},
          YEAR = {2002},
          NOTE = {Unfinished monograph, recompiled 2014, available
          at \url{http://www.stat.berkeley.edu/$\sim$aldous/RWG/book.html}}
          }
