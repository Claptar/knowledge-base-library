Let _X_ and _Y_ be random variables defined on Ω and let _A_ be an event with **P** ( _A_ ) _>_ 0.

- _X_ is independent of _A_ if either of the following hold: _pX |A_ ( _x_ ) = _pX_ ( _x_ ) _∀x pX ,A_ ( _x_ ) = _pX_ ( _x_ ) **P** ( _A_ ) _∀x_

- _X_ and _Y_ are independent if either of the following hold: _pX |Y_ ( _x|y_ ) = _pX_ ( _x_ ) _∀x∀y_

- _pX ,Y_ ( _x, y_ ) = _pX_ ( _x_ ) _pY_ ( _y_ ) _∀x∀y_
