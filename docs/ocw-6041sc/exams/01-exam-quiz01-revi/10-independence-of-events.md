- Events _A_ and _B_ are **independent** if and only if **P** ( _A ∩ B_ ) = **P** ( _A_ ) **P** ( _B_ )

or **P** ( _A B|_ ) = **P** ( _A_ ) if **P** ( _B_ ) _>_ 0

- Events _A_ and _B_ are **conditionally independent** given an event C if and only if

**P** ( _A ∩ B|C_ ) = **P** ( _A|C_ ) **P** ( _B|C_ )

or

**P** ( _A|B ∩ C_ ) = **P** ( _A|C_ ) if **P** ( _B ∩ C_ ) _>_ 0
