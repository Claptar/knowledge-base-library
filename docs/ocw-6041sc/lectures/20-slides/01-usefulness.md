- Let _Z_ be a standard normal r.v. (zero mean, unit variance)

- **Theorem:** For every _c_ :

**P** ( _Zn ≤ c_ ) _→_ **P** ( _Z ≤ c_ )

**What exactly does it say?**

- CDF of _Zn_ converges to normal CDF

- not a statement about convergence of PDFs or PMFs
