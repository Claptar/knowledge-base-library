- **null hypothesis** _H_ 0:

   - _X ∼ pX_ ( _x_ ; _H_ 0) [or _fX_ ( _x_ ; _H_ 0)]

- **alternative hypothesis** _H_ 1: _X ∼ pX_ ( _x_ ; _H_ 1) [or _fX_ ( _x_ ; _H_ 1)]
