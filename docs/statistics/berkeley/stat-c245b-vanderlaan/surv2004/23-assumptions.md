# Assumptions

**Source:** [`surv2004.pdf`](https://vanderlaan-lab.org/teach-files/surv2004.pdf) · **Licence:** unresolved · Converted 2026-09-14 from `.pdf` (lossy)

!!! warning "Converted from PDF — mathematics may be mangled"

    original before relying on it, and mark repairs `**Unverified.**`

There are 2 assumptions on censoring for the estimators: 1) _G_ ( _c|X_ ) _≡ P_ ( _C < c|X_ ) = _G_ ( _c|W_ ) <u>¯</u> _I_ <u>(</u> _T_ _<u>≤t</u>_ <u>)</u> 2) _G_ ( _V |W_ )<sup>_>_0</sup>

_FX_ almost everywhere, where _G_<sup>¯</sup> ( _c|W_ ) _≡ P_ ( _C ≥ c|W_ )

The second assumption implies that, given V, there has to be positive probability _C > V_ if _I_ ( _T ≤ t_ ).
