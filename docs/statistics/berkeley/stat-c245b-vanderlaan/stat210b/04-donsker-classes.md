# Donsker Classes

**Source:** [`stat210b.pdf`](https://vanderlaan-lab.org/teach-files/stat210b.pdf) · **Licence:** unresolved · Converted 2026-09-14 from `.pdf` (lossy)

If the empirical process _Gn_ converges in distribution in ( _l_<sup>_∞_</sup> ( _F_ ) _, ∥·∥F_ ) to the _P_ -Brownian Bridge _G_ , we say that _F_ is a _P-Donsker class_ . Because the finite dimensional distributions of _G_ are multivariate Normal, saying that _F_ is Donsker is saying that the CLT holds uniformly over _F_ . Note that all Donsker classes are Glivenko-Cantelli classes, but the converse is not true (consider the function class to be a single function _f ∈ L_<sup>1</sup> ( _P_ ) but _f ∈/ L_<sup>2</sup> ( _P_ )). As with Glivenko-Cantelli classes, _F_ can only be Donsker if the class is not too big. This leads to the _second major goal of empirical process theory_ : Determine sufficient conditions for _F_ to be Donsker that are as easy to check as possible, but apply to as large a class _F_ as possible.
