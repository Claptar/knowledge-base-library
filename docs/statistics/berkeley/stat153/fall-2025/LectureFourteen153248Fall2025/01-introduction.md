# **STAT 153 & 248 - Time Series Lecture Fourteen**

**Fall 2025, UC Berkeley**

Aditya Guntuboyina

October 14, 2025

We shall discuss three simple high-dimensional models for time series _{yt}_ . The first model is the same as the high-dimensional linear regression model from the previous few lectures; but we shall write it slightly differently. The second model is a model on variances; it was introduced near the end of last lecture. The third model is a variance model on the DFT and will be referred to as the Spectrum model.
