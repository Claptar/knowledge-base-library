# 79. Homework Assignments Index

## What this covers

This chapter documents the homework index page for STAT 153 (Introduction to Time Series, UC
Berkeley, Fall 2024). The page itself carries no mathematical content: it is a table of contents
listing the five problem sets assigned during the semester, each with links to its PDF statement,
its R Markdown source, and the folder in the course's GitHub repository. It assumes only that the
reader knows the course exists and wants to find a particular assignment.

## The assignments

Five homework sets were assigned over the semester, numbered Homework 1 through Homework 5. Each
is distributed as a PDF problem statement, together with the R Markdown file used to typeset it,
both hosted in the course's GitHub repository (`berkeley-stat153/fall-2024`).

- **Homework 1** — problem statement and R Markdown source in `homeworks/homework1/`.
- **Homework 2** — problem statement and R Markdown source in `homeworks/homework2/`.
- **Homework 3** — problem statement and R Markdown source in `homeworks/homework3/`.
- **Homework 4** — problem statement and R Markdown source in `homeworks/homework4/`.
- **Homework 5** — problem statement and R Markdown source in `homeworks/homework5/`.

The index page gives no further description of any assignment — no topic, no due date, no point
values — so nothing beyond the count and the file layout above can be reported here. The actual
problem text lives in the linked PDFs and Rmd files, which are separate documents from this index
and are not part of the material supplied for this chapter.
