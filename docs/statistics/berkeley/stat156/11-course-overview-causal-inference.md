# 11. Course Overview: Causal Inference

## What this covers

The only input for this chapter is the course syllabus page for Stat 156/256, which describes
what the course covers rather than teaching any of it. It answers a narrower question than the
other chapters in this book: not "what is causal inference" but "what is this course about, and
how does it run". There is no lecture, no worked example and no mathematics behind this page, so
none is manufactured here — this chapter records the course's own description of its scope and
format, and nothing more.

## What the course is about

Stat 156/256 is an introduction to causal inference built on the potential outcomes framework and
causal diagrams. The syllabus names four topics the course covers: randomized experiments,
observational studies, instrumental variables, and mediation analysis. It states that these
methods are applied to fields such as medicine and public policy.

## How the course runs

The syllabus describes a split between two kinds of session: lectures present concepts and
methods, while lab sections focus on applications, derivations, and worked problems, using the
statistical language R. The course is described as emphasizing both theory and data analysis.
