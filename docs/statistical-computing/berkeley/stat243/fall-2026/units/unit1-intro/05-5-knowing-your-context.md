# 5. Knowing your context

**Source:** [`units/unit1-intro.qmd`](https://github.com/berkeley-stat243/fall-2026/blob/c74395ec9c420005c80bbcc5f315729aaee3dc32/units/unit1-intro.qmd) · **Licence:** CC BY 4.0 · Converted 2026-09-14 from `.qmd` (lossless)

Here are the key things to be aware of when you are in the shell or executing code:

 - What machine am I on?
 - What user am I?
 - What is the current working directory?
 - What git branch am I in (if the working directory is in a Git repo)?
 - What Conda environment am I in (if relevant)?
