# Course description

**Source:** [`syllabus.qmd`](https://github.com/berkeley-stat243/fall-2026/blob/c74395ec9c420005c80bbcc5f315729aaee3dc32/syllabus.qmd) · **Licence:** CC BY 4.0 · Converted 2026-09-14 from `.qmd` (lossless)

Statistics 243 is an introduction to statistical computing, taught using
Python, with 'statistical' defined broadly to include data science and machine learning.

This fall is the first time we are offering the material as two separate, but closely-related
half-semester two-credit courses.

**Stat 243A** will focus on programming concepts and will include data and text
manipulation, regular expressions, data structures, functions and variable scope,
memory use, efficiency, debugging, testing, parallel processing, and working with large datasets.

**Stat 243B** will focus on numerical computing topics and will include numerical
linear algebra, computer arithmetic/precision, simulation studies and
Monte Carlo methods, numerical linear algebra, and numerical optimization (including a unit focusing on optimization for deep learning).

A goal is that coverage of these topics
complement the models/methods discussed in the rest of the
statistics/biostatistics graduate curriculum. We will also cover the
basics of UNIX/Linux, in particular shell scripting and
operating on remote servers, as well as a bit of R.

### What the courses are not

 - While both courses are taught using Python and you will learn a lot about using
Python at an advanced level (primarily in Stat 243A), these are not courses about learning Python. Rather the focus of the course is computing for statistics and data science more generally, using Python to illustrate the concepts.
 - These are not courses that will cover specific statistical/machine learning/data analysis methods.

### Prerequisites

Informal prerequisites: If you are not a statistics or biostatistics
graduate student, please chat with me if you're not sure if this course
makes sense for you.

For both courses, a background in probability and statistics is expected, as well as a basic ability to
operate on a computer (but I do not assume familiarity with the
UNIX-style command line/terminal/shell).

In general, the [material in the Statistics Department  computational skills workshop](https://computing.stat.berkeley.edu/compute-skills-2026) is a
good reference for the courses.
While many of you will have attended the workshop, it's not required to take the course.
But if you didn't attend, it's worthwhile to look through the workshop materials
in general and for additional information on various topics we'll see in
Units A1-A4.

#### Stat 243A

For Stat 243A, I am also  expecting you
will know the basics of Python, at the level of the
[Python material in our computing skills workshop](https://computing.stat.berkeley.edu/compute-skills-2026/units/intro-python.html). If you don't have that background
you'll need to spend time in the initial couple weeks getting up to
speed. The workshop materials are a good resource.


#### Stat 243B

For Stat 243B, you should be comfortable with calculus and linear algebra.
In addition, you should be comfortable programming in Python, but your experience does not need to be equivalent to Stat 243A.
