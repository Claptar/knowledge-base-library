**Source:** [`section/ps0/practice.tex`](https://github.com/berkeley-stat243/stat243-fall-2014/blob/49fcee4ef42342d81d010e586b69d92a94bbb12f/section/ps0/practice.tex) · **Licence:** unresolved · Converted 2026-09-14 from `.tex` (high)

1.  Create the following:

    1.  Create a matrix with only the numeric elements of `df1` and call it `m1`

    2.  Create a new matrix `m2` with only the rows where `df1$f` is `TRUE`

    3.  Create a new data frame `df2` with only the rows where `z` is non-negative and has all columns but `z`

    4.  Create a new data frame `df3` without the 3rd and 17th rows of `df1`

    5.  Create a new data frame `df4` with only the even rows of `df1`
