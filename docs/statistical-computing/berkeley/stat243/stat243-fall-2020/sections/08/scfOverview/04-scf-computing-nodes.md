The SCF cluster is has several compute nodes, which you can list using `sitehosts compute` . They are also listed on this page.

The nodes are divided into 3 partitions, the two listed above and a GPU partition, with restrictions associated with each. Any job you submit must be submitted to a partition to which you have access.

For the puposes of this class, we only have access to the _low_ partition.
