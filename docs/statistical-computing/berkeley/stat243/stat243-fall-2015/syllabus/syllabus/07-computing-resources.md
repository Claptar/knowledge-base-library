Most work for the course can be done on your laptop. We will also provide a Linux virtual machine (VM) with all required software that should eliminate any issues with installation and getting the necessary software. If you wish to do your assignments on your own machine rather than on the VM, keep in mind that it is your responsibility to get the required resources (such as being able to work in a UNIX terminal window) working on the your own computer. To use the VM, go to http://bce.berkeley.edu. We can try to help with Windows-related issues but this help will necessarily be limited by our limited experience with Windows.

Those of you in Statistics can also make use of the Statistical Computing Facility (SCF) network of Linux and Mac computers. Anyone not in Statistics who would like an SCF account is also welcome to get one for the semester - see Chris for an account form. The computer rooms in 342 and 432 Evans provide Mac desktops; you can also remotely log in to the SCF system from other campus computers or from home. The software needed for the course is as follows:

- Access to the UNIX command line (e.g., the Linux virtual machine, an SCF machine, or a Mac laptop)

- Git

- R (RStudio is recommended but by no means required)

- Python (later in the course)

Some tips for software installation are in the ’howtos’ directory of the Git repository.
