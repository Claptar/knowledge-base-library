Please see the material in _our tutorial on the basics of UNIX_ to get up to speed on working in a UNIX-style command line environment. We’ll do a bit of demo in the first class. If what you see seems quite familiar, you can probably skip that tutorial. If what you see is not familiar, please work through the tutorial and (optionally) attend section on Friday August 27 to work on the problems at the end of the tutorial and be able to ask questins of the GSI and other students.

For an alternative introduction (which also includes some of the topics we’ll discuss in Unit 4 on shell scripting), see this Software Carpentry tutorial.
